Compact Content Delivery Network (CDN) with Intelligent DNS Routing
Requirements: Build a content delivery network consisting of one Origin Server, three Edge Cache Servers located in distinct simulated network zones (using Docker/Mininet), and a custom-implemented Authoritative DNS Server. The system must automatically route users to the Edge Server with the lowest latency or the lightest load, while ensuring data synchronization whenever the original content is updated.
